# ml/configs

One JSON config per experiment. A config is copied into the experiment's results folder when it runs, so results
always travel with the exact parameters that produced them.

| Config | Experiment |
|---|---|
| `e001.json` | E-001 — single-frame localisation and scoring error of the deterministic baseline |
| `e004a.json` | E-004a — planning focal lengths (priors), decision thresholds, synthetic sanity scenario |
| `e005.json` | E-005 — Cramér–Rao bound parameters |
