Step-by-step assembly instructions:
1. Print all parts per PRINTING_AND_TOLERANCES.md
2. Install M3 heat-set inserts into chassis (6 locations)
3. Install steel dowel pins (3mm × 8mm and 2mm × 6mm) into chassis top face
4. Test-fit phone adapter onto chassis — pins should engage with light press
5. Insert phone into adapter cradle against locating faces, engage retention clips
6. Verify camera clearance — no contact with lens glass
7. Slide ballast carriage into T-slot from either end
8. Install ballast weights (steel washers, M8 × 2mm, qty per mass target)
9. Lock carriage position with M3 × 12 thumb screw
10. Verify no rattle, no obstruction
11. Run mass-properties solver: `python scripts/antigravity_cad_mass_properties.py --phone <profile>`
